# Política de Privacidad — Focus Flow

**Última actualización:** 2025-07-15

## Introducción

Focus Flow es una aplicación de productividad diseñada para ayudarte a gestionar tus tareas y sesiones de trabajo. Tu privacidad es importante para nosotros. Esta política describe cómo la aplicación maneja (o no maneja) tus datos.

## Funcionamiento sin conexión

Focus Flow opera **completamente sin conexión**. La aplicación no realiza ninguna comunicación de red. No se conecta a internet, no envía datos a servidores externos y no requiere conexión a internet para funcionar.

## Cuentas de usuario

Focus Flow **no requiere cuentas de usuario, autenticación ni registro** de ningún tipo. No existe un sistema de inicio de sesión, ni se solicitan credenciales, correos electrónicos u otra información personal para acceder a la aplicación.

## Recopilación de datos

Focus Flow **no recopila analíticas, informes de errores ni datos de telemetría**. No utilizamos herramientas de seguimiento, no monitorizamos el uso de la aplicación y no enviamos información de diagnóstico a ningún servidor.

## Publicidad

Focus Flow **no muestra publicidad** de ningún tipo. No se integran redes publicitarias ni servicios de anuncios en la aplicación.

## Datos compartidos con terceros

Focus Flow **no comparte datos con terceros**. Ninguna información del usuario es transmitida, vendida ni proporcionada a empresas, servicios o individuos externos.

## Almacenamiento de datos

Todos los datos generados por el uso de la aplicación (tareas, sesiones de pomodoro, estadísticas y preferencias) se almacenan **exclusivamente en el dispositivo local** del usuario. Los datos no se transfieren ni se respaldan en ningún servidor externo. Si desinstalas la aplicación, todos los datos almacenados se eliminan permanentemente del dispositivo.

# Privacy Policy — Focus Flow

**Last updated:** 2025-07-15

## Introduction

Focus Flow is a productivity application designed to help you manage your tasks and work sessions. Your privacy is important to us. This policy describes how the application handles (or does not handle) your data.

## Offline operation

Focus Flow operates **entirely offline**. The application does not perform any network communication. It does not connect to the internet, does not send data to external servers, and does not require an internet connection to function.

## User accounts

Focus Flow **does not require user accounts, authentication, or registration** of any kind. There is no login system, and no credentials, emails, or other personal information are requested to access the application.

## Data collection

Focus Flow **does not collect analytics, crash reports, or telemetry data**. We do not use tracking tools, do not monitor application usage, and do not send diagnostic information to any server.

## Advertising

Focus Flow **does not display advertisements** of any kind. No advertising networks or ad services are integrated into the application.

## Data shared with third parties

Focus Flow **does not share data with third parties**. No user information is transmitted, sold, or provided to external companies, services, or individuals.

## Data storage

All data generated through the use of the application (tasks, pomodoro sessions, statistics, and preferences) is stored **exclusively on the user's local device**. Data is not transferred to or backed up on any external server. If you uninstall the application, all stored data is permanently deleted from the device.
